# Vendored TOTP conformance test vectors

The JSON files in this folder are **vendored, byte for byte**, from the
normative test-vector annex of the TOTP specification at
[OpenChargingTechnology/Whitepapers → TimeBasedOneTimePasswords/test-vectors/](https://github.com/OpenChargingTechnology/Whitepapers/tree/master/TimeBasedOneTimePasswords/test-vectors),
where they are generated by an independent reference implementation and also
run against TOTP.ts — never edit them here.

To update: regenerate from the conformance suite
[OpenChargingCloud/TOTPConformanceTests](https://github.com/OpenChargingCloud/TOTPConformanceTests),
whose generator invocation mirrors the annex into this folder —

```
python libs/specification/TimeBasedOneTimePasswords/tools/generate-test-vectors.py \
    --mirror libs/Hermod/HermodTests/TOTP/TestVectors \
    --mirror libs/TOTP.TS/test/vectors
```

— then commit the repositories in order: specification, implementations,
conformance pins. The conformance suite compares this copy against the annex
on every CI and nightly run, so drift cannot go unnoticed.

`TOTPVectorTests.cs` runs the vectors; a vendored copy instead of a submodule
keeps this repository's test suite self-contained.
