# Vendored TOTP conformance test vectors

The JSON files in this folder are **vendored, byte for byte**, from
[OpenChargingCloud/TOTPConformanceTests](https://github.com/OpenChargingCloud/TOTPConformanceTests)
(`TestVectors/`), where they are generated by an independent reference
implementation and also run against TOTP.ts — never edit them here.

To update: regenerate in the conformance repository
(`python tools/generate-test-vectors.py` mirrors them into this folder when
Hermod is checked out as its submodule) and commit both repositories. The
conformance suite compares this copy against the canonical files on every CI
and nightly run, so drift cannot go unnoticed.

`TOTPVectorTests.cs` runs the vectors; a vendored copy instead of a submodule
because the conformance repository already contains Hermod as a submodule —
the other direction would be cyclic.
